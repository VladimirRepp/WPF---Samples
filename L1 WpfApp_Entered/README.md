# L1 WpfApp_Entered — Форма регистрации

**Второй шаг** в изучении WPF. Этот проект знакомит с более сложными элементами управления и их комбинацией на примере формы для ввода регистрационных данных. Мы продолжаем использовать простую архитектуру Code-behind, чтобы сосредоточиться на UI и событиях.

---

## 🎯 Цель проекта

Научиться создавать функциональные формы ввода, используя разнообразные элементы WPF: переключатели, списки, флажки и поля ввода. Вы освоите компоновку с помощью `StackPanel` и `Grid`, а также реализуете простую валидацию данных.

## 📚 Шпаргалка по новым XAML-элементам (для студентов)

В этом проекте вы встретите элементы, которые не использовались в прошлом калькуляторе. Вот их краткое описание:

| Элемент | Назначение | Пример использования |
| :--- | :--- | :--- |
| **`<StackPanel>`** | **Контейнер макета**. Располагает дочерние элементы вертикально или горизонтально в один ряд. Идеален для группировки связанных элементов (например, группы переключателей). | `<StackPanel Orientation="Vertical">` |
| **`<RadioButton>`** | **Переключатель**. Позволяет выбрать **один** вариант из группы. Группируются автоматически, если находятся в одном контейнере. | `<RadioButton Content="Мужской" GroupName="Gender" />` |
| **`<ComboBox>`** | **Выпадающий список**. Позволяет выбрать один вариант из раскрывающегося списка. Экономит место на форме. | `<ComboBox x:Name="CountryComboBox">`<br>`<ComboBoxItem>Россия</ComboBoxItem>` |
| **`<CheckBox>`** | **Флажок**. Позволяет выбрать **несколько** независимых опций (вкл/выкл). | `<CheckBox Content="Согласен с условиями" />` |
| **`MessageBox`** | **Диалоговое окно**. Используется в коде (C#) для отображения сообщений, предупреждений или запроса подтверждения. Не является XAML-элементом. | `MessageBox.Show("Данные сохранены!", "Успех");` |

### 🧩 Обработчики событий (Code-behind)

Вся логика в этом проекте пишется в файле `MainWindow.xaml.cs`. Это классический подход для начала.

*   **Событие `Click`** — возникает при нажатии на кнопку (`Button`).
*   **Событие `SelectionChanged`** — возникает при изменении выбора в `ComboBox` или `RadioButton`.
*   **Событие `TextChanged`** — возникает при изменении текста в `TextBox`.

```csharp
// Пример обработчика для кнопки "Зарегистрироваться"
private void RegisterButton_Click(object sender, RoutedEventArgs e)
{
    // 1. Собрать данные из всех полей
    string name = NameTextBox.Text;
    string gender = (MaleRadioButton.IsChecked == true) ? "Мужской" : "Женский";
    string country = (CountryComboBox.SelectedItem as ComboBoxItem)?.Content.ToString();
    bool isAgreed = AgreeCheckBox.IsChecked ?? false;

    // 2. Простая валидация
    if (string.IsNullOrWhiteSpace(name) || string.IsNullOrEmpty(country))
    {
        MessageBox.Show("Заполните все поля!", "Ошибка", MessageBoxButton.OK, MessageBoxImage.Warning);
        return;
    }

    if (!isAgreed)
    {
        MessageBox.Show("Необходимо согласие с условиями", "Ошибка", MessageBoxButton.OK, MessageBoxImage.Warning);
        return;
    }

    // 3. Успешная регистрация
    MessageBox.Show($"Регистрация успешна!\nИмя: {name}\nСтрана: {country}", "Успех");
}
```

## 🧩 Как это собрано в форме регистрации

1.  **Структура макета**: Основная сетка `Grid` делит окно на логические части. Внутри ячеек часто используется `StackPanel` для вертикальной группировки полей и их подписей.
2.  **Ввод данных**:
    *   `TextBox` — для имени, логина, пароля.
    *   `RadioButton` — для выбора пола.
    *   `ComboBox` — для выбора страны из списка.
    *   `CheckBox` — для принятия условий.
3.  **Валидация**: При нажатии на кнопку "Зарегистрироваться" или "Войти" код проверяет, что обязательные поля не пусты и условия приняты. Результат выводится в `MessageBox`.
4.  **Обратная связь**: Все сообщения об ошибках и успехе показываются через `MessageBox`.
