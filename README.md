# WPF---Samples

**Коллекция учебных проектов по WPF и XAML** для постепенного освоения платформы — от базовых элементов интерфейса до архитектурного паттерна MVVM.

Этот репозиторий создан как пошаговое руководство для начинающих. Проекты расположены в порядке усложнения, чтобы вы могли плавно переходить от простого к сложному.

---

## 🗺️ Путь обучения

Проекты разделены на два блока. Рекомендуется изучать их строго по порядку внутри каждого блока.

### Блок 1: Основы UI и XAML
*Знакомство с элементами управления, разметкой и простой логикой.*

| Проект | Описание | Что вы изучите |
| :--- | :--- | :--- |
| **L0 WpfApp_Calculate** | Простой калькулятор с базовой реализацией. | Основы событийной модели WPF, работа с `Click`. |
| **L1 WpfApp_Entered** | Форма для ввода данных (логин/пароль). | Различные полезные UI-элементы (`TextBox`, `PasswordBox`, `CheckBox`). |
| **L2 WpfApp_ToDoList** | Приложение для ведения списка задач. | Работа со списками (`ListBox`), добавление и удаление элементов. |
| **L3 WpfApp_ColorChanger** | Первое знакомство с механизмом привязки данных. | Основы **Binding**, синхронизация данных между элементами. |
| **L4 WpfApp_Bank** | Простое банковское приложение. | Объединение бизнес-логики и UI без сложной архитектуры. |

### Блок 2: Архитектура и MVVM
*Переход к паттернам, разделению ответственности и тестируемому коду.*

| Проект | Описание | Что вы изучите |
| :--- | :--- | :--- |
| **Wpf_Counter** | Простейшее приложение-счетчик. | Базовое понимание паттерна **MVVM**: ViewModel, команды и привязки. |
| **Wpf_StudentManagment** | Система управления данными студентов. | Глубокое разделение UI и логики, работа с коллекциями в MVVM. |
| **Wpf_TreasureHunt** | Игровой проект "В поисках сокровищ". | Полноценное применение MVVM в игровом контексте. |

---

## 💡 Совет

*   В проектах из **Блока 1** старайтесь сначала разобраться с XAML-разметкой, а затем с кодом позади (`.xaml.cs`).
*   В проектах из **Блока 2** обратите внимание на то, как ViewModel отделена от View — это ключевая идея MVVM.
*   Не бойтесь ломать код — на ошибках учатся!
