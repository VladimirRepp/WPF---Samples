**Первый шаг** в мире WPF. Этот проект создан, чтобы на простом примере калькулятора освоить базовые элементы управления и принципы разметки XAML.

---

## 🎯 Цель проекта

Понять, как устроено приложение WPF, научиться работать с **Grid** для создания гибкого макета и использовать основные UI-элементы: кнопки, поля ввода и текстовые блоки.

---

## 📚 Шпаргалка по XAML-элементам (для студентов)

Ниже кратко объяснены все ключевые элементы, использованные в проекте. Это ваш мини-словарь для старта.

| Элемент | Назначение | Пример использования |
| :--- | :--- | :--- |
| **`<Grid>`** | **Контейнер макета**. Организует дочерние элементы в виде таблицы. Это «скелет» вашего окна. | Оборачивает всё содержимое окна. |
| **`<Grid.RowDefinitions>`** | Определяет **строки** сетки. Задает их высоту (фиксированную, автоматическую или пропорциональную `*`). | `<RowDefinition Height="Auto"/>`<br>`<RowDefinition Height="*"/>` |
| **`<Grid.ColumnDefinitions>`** | Определяет **столбцы** сетки. Задает их ширину. | `<ColumnDefinition Width="*"/>` |
| **`<TextBlock>`** | **Статический текст** для отображения информации, подписей, результатов. Только для чтения. | `<TextBlock Text="Результат:" />` |
| **`<TextBox>`** | **Поле ввода** текста. Позволяет пользователю вводить данные (например, число). | `<TextBox Text="0" />` |
| **`<Button>`** | **Кнопка**. Главный элемент для действий пользователя. Генерирует событие `Click`. | `<Button Content="=" Click="ButtonEquals_Click" />` |

### 📐 Атрибуты разметки

*   **`Grid.Row` / `Grid.Column`** — указывают, в какой строке/столбце находится элемент. Нумерация начинается с **0**.
*   **`Grid.RowSpan` / `Grid.ColumnSpan`** — заставляют элемент занимать несколько строк или столбцов (полезно для кнопки `=`).
*   **`Height="Auto"`** — строка подстраивается под высоту своего содержимого.
*   **`Height="*"`** — строка занимает всё оставшееся пространство (пропорционально звездам, например `2*`).

---

## 🧩 Как это собрано в калькуляторе

1.  **Макет (`Grid`)**: Окно поделено на строки (для поля вывода, для кнопок-цифр, для кнопок действий) и столбцы (для рядов кнопок).
2.  **Отображение (`TextBlock` или `TextBox`)**: Используется для показа вводимого числа и результата вычислений.
3.  **Ввод (`Button`)**: Каждый знак операции — это кнопка, которая обрабатывает нажатие в коде (`Click`).
4.  **Логика**: В файле `MainWindow.xaml.cs` пишутся обработчики событий, которые управляют вычислениями.
